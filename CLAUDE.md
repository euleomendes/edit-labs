# Edit Labs

If someone asks you to install Edit Labs on their Mac, run the one-line installer and nothing else:

```bash
curl -fsSL https://raw.githubusercontent.com/euleomendes/edit-labs/main/install.sh | bash
```

It installs into `~/Edit Labs`, adds the "Edit Labs" app to Applications and opens the editor. Do not ask the person to double-click the `.command` files from a downloaded zip: macOS blocks them with a malware warning.
